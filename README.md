# ArbiyshkynBot

Арбитражный и торговый бот для криптовалютного рынка на **.NET 10** (Clean Architecture).
## 🧠 ИИ-анализатор (OpenRouter)

По умолчанию модуль ИИ-анализа **отключён** для экономии токенов и упрощения тестирования базовых стратегий в режиме симуляции.

### Как активировать:
1. Получите API-ключ в личном кабинете [OpenRouter](https://openrouter.ai/).
2. Откройте файл `.env` в корне проекта.
3. Измените параметры конфигурации:

   ENABLE_AI_ANALYZER=true
   OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь
